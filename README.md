# Wolves Hurling Club Site

A private, mobile-friendly website for Wolves Hurling club.

- **Announcements** from the board, emailed to all members, with one-tap sharing to the club WhatsApp group
- **Schedule** of matches and training, with a private calendar feed for each member
- **Availability** — going, not going or maybe for every fixture
- **Questions** to the board, kept private
- **Photo gallery** with upload and approval

Membership is invite-only. Nothing is visible without an approved account.

## Stack
Next.js, TypeScript, Supabase, Resend, Vercel.
